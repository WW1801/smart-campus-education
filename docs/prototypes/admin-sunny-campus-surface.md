## Scope and mode

The Sunny Campus administrator comparison contains three standalone Operate-mode HTML prototypes and one gallery. It replaces the visual direction, not the existing comparison files.

## Audience, job and action

Campus administrators compare how a service portal, teaching-week dispatcher and focused action queue support the same daily administrative work. Each prototype keeps the primary work item visible in the first viewport.

## Content and constraints

All values are representative demo data. The prototypes use shared local CSS and JavaScript, call no APIs and do not modify Vue routes.

## Direction and memorable moment

Sunny Campus uses clear sky blue, cloud-white work surfaces, deep ocean navigation and bright-blue actions. The three memorable structures are the service-status ribbon, the five-day operating runway and the single-task focus panel.
