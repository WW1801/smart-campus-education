## Scope and mode

`docs/prototypes/admin-dashboard.html` is an independent administrator workbench prototype in Operate mode.

## Audience, job and action

Campus administrators need to recognize today’s urgent teaching-administration work, open the relevant workflow, and track upcoming academic deadlines. The prototype’s primary action is the row-level action in the priority ledger.

## Content and constraints

The interface uses only representative, non-real demonstration data. It reflects existing system modules: people, courses, schedules, grades, attendance, graduation and academic warning. The artifact must remain a dependency-free HTML/CSS/JavaScript preview and must not replace production Vue pages.

## Direction and memorable moment

The “academic audit ledger” direction treats the first screen as an ivory-paper academic record: a navy archival index on the left, five work items in the centre, and deadlines on the right. The memorable moment is the priority ledger leading directly to a named action instead of a generic metrics-card summary.

## Unresolved decisions

No production dashboard route, real API bindings, or final brand assets have been chosen.
