## Scope and mode

`docs/prototypes/admin-dashboard-ledger-v2.html` is a standalone administrator workbench prototype in Operate mode. It is a comparison artifact and does not replace `admin-dashboard.html`.

## Audience, job and action

Campus administrators need to identify the next item requiring action, inspect the cited reason, then open the matching workflow. The primary action is the row-level action in the first, prioritized ledger.

## Content and constraints

All values are representative demo data. The artifact remains dependency-free HTML/CSS/JavaScript and does not connect to the Vue app or back-end APIs.

## Direction and memorable moment

The “batch dossier” form gives every task a folio number, batch, evidence line, status stamp and direct action. It starts with the ledger, then provides evidence and an AI briefing as supporting material. Desktop uses an index / work area / milestone three-column layout.
