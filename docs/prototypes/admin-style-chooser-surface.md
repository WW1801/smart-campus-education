## Scope and mode

`docs/prototypes/admin-style-chooser.html` is an independent style-selection artifact in Operate mode. It does not replace the existing administrator prototypes or design system.

## Audience, job and action

The project owner compares four distinct directions for the same administrator workbench, then records one as the candidate for a future standalone implementation.

## Content and constraints

All dashboard content is representative demo data. The file is dependency-free HTML/CSS/JavaScript; it neither calls APIs nor changes project routing.

## Direction and memorable moment

The selection mechanism itself is the surface: four visual miniatures above one live preview. Each choice changes the preview’s palette, type, navigation grammar, density and control character.

## Unresolved decisions

No style is selected, no final design system is recorded, and production integrations remain outside this artifact.
