# 校园教务系统 量化业务规则文档

## 一、成绩计算规则

### 1.1 总成绩计算

**规则描述**：根据课程类型，按不同权重组合平时成绩与考试成绩计算总成绩。

**计算公式**：

| 课程性质 | 平时成绩权重 | 考试成绩权重 | 适用范围 |
|---------|------------|------------|---------|
| 必修课（compulsory） | 30% | 70% | 所有必修课程 |
| 专业选修课（elective_major） | 40% | 60% | 专业方向选修课程 |
| 公共选修课（elective_public） | 50% | 50% | 跨专业通识选修课程 |

```
total_score = usual_score × W_usual + exam_score × W_exam
```

> 权重可在系统配置表中按课程维度覆盖，以上为默认值。

**适用场景**：教师录入成绩时系统自动计算；管理员审核时校验。

**异常处理**：

| 异常情况 | 处理方式 |
|---------|---------|
| 平时成绩为 NULL，考试成绩不为 NULL | total_score 不自动计算，需教师手动填写 |
| 考试成绩为 NULL（缺考） | total_score = 0，自动标记为不及格 |
| 平时成绩和考试成绩均为 NULL | 不允许提交，提示"至少填写一项成绩" |
| 成绩超出 0~100 范围 | 前端/后端双重校验，拒绝提交 |
| total_score 与公式计算结果不一致（手动填写场景） | 系统记录警告日志，但不阻止提交 |

### 1.2 及格/挂科判定

**规则描述**：根据总成绩判定课程是否通过。

**判定条件**：

| 条件 | 结果 |
|------|------|
| total_score ≥ 60 | 及格（pass） |
| total_score < 60 | 不及格（fail） |
| 考试成绩缺考（exam_score IS NULL） | 不及格（fail），无论平时成绩多少 |

**适用场景**：成绩审核通过后自动判定；绩点计算依赖此判定。

**异常处理**：

- 成绩状态为 `pending` 时，不进行及格判定
- 成绩状态为 `rejected` 时，及格判定结果不生效
- 补考成绩覆盖原始成绩时，标注补考标记（通过 remark 字段或扩展字段）

### 1.3 绩点（GPA）计算

**规则描述**：采用标准4.0制绩点，用于衡量学生学业表现。

**计算公式**：

```
单科绩点计算：
  score ≥ 60 时：grade_point = (total_score - 50) / 10
  score < 60 时：grade_point = 0

示例：
  60分 → 1.0    70分 → 2.0    80分 → 3.0    90分 → 4.0
  55分 → 0      65分 → 1.5    75分 → 2.5    85分 → 3.5

平均绩点（GPA）计算：
  GPA = Σ(单科绩点 × 课程学分) / Σ课程学分

  仅计算 status = 'approved' 且及格的课程
  不及格课程绩点为0，但学分计入分母（影响GPA下降）
```

**适用场景**：学生成绩单展示；毕业资格审核中学分绩点要求。

**异常处理**：

| 异常情况 | 处理方式 |
|---------|---------|
| 无已审核成绩 | GPA 显示为 "--"，不参与排名 |
| 重修课程 | 取最高成绩计算绩点，学分不重复计入 |
| 跨专业选修课 | 纳入GPA计算，除非课程标记为"不计入GPA" |

### 1.4 成绩审核流转

**规则描述**：成绩录入后需经审核方可生效，确保成绩准确。

**流转状态**：

```
pending（待审核）
    │
    ├── 院系管理员审核通过 → approved（审核通过）→ 自动判定及格/不及格
    │
    └── 院系管理员审核驳回 → rejected（审核驳回）→ 教师修改后重新提交 → pending
```

**判定条件**：

| 操作 | 条件 | 结果 |
|------|------|------|
| 教师提交成绩 | usual_score 和 exam_score 至少填写一项 | 状态变为 pending |
| 院系管理员审核通过 | total_score 不为空且 ≥ 0 | 状态变为 approved，自动判定 pass/fail |
| 院系管理员审核驳回 | 需填写驳回原因 | 状态变为 rejected，通知教师 |
| 教师修改已驳回成绩 | 修改成绩后重新提交 | 状态变为 pending |

**适用场景**：学期结束时教师批量录入成绩；院系管理员统一审核。

**异常处理**：

- 已 approved 的成绩不可直接修改，需走"成绩更正"流程（需教务处审批）
- 一门课程的所有学生成绩需在学期结束4周内完成录入
- 超期未录入的系统自动发送催录通知

## 二、排课冲突规则

### 2.1 冲突判定维度

**规则描述**：排课时需检测三个维度的冲突，确保同一时间资源不被重复占用。

**判定条件**：

| 冲突维度 | 判定公式 | 说明 |
|---------|---------|------|
| 教师时间冲突 | 同一学期 + 同一教师 + 同一天 + 时间段重叠 | 一位教师同一时间只能上一门课 |
| 教室时间冲突 | 同一学期 + 同一教室 + 同一天 + 时间段重叠 | 一间教室同一时间只能排一门课 |
| 班级时间冲突 | 同一学期 + 同一班级 + 同一天 + 时间段重叠 | 一个班级同一时间只能上一门课 |

**时间段重叠判定**：

```
两个时间段 [start1, end1] 和 [start2, end2] 重叠的条件：
  start1 <= end2 AND start2 <= end1

示例：
  课程A：第1~2节，课程B：第2~3节 → 重叠（第2节冲突）
  课程A：第1~2节，课程B：第3~4节 → 不重叠
```

**适用场景**：手动排课时的实时冲突检测；自动排课算法的约束条件。

**异常处理**：

- 冲突检测必须在保存前执行，存在冲突则拒绝保存并返回冲突详情
- 冲突详情需明确指出：与哪条排课记录冲突、冲突维度（教师/教室/班级）

### 2.2 冲突解决优先级

**规则描述**：当排课存在多种可行方案时，按优先级顺序选择最优方案；当必须牺牲某一维度时，按优先级决定保留/调整哪条排课。

**优先级排序**：

| 优先级 | 维度 | 说明 |
|-------|------|------|
| P0（最高） | 教师时间 | 教师不可分身，冲突不可调和 |
| P1 | 教室容量 | 教室容量必须 ≥ 实际上课人数 |
| P2 | 教室时间 | 教室冲突可通过更换教室解决 |
| P3（最低） | 班级时间 | 班级冲突可通过调课解决 |

**解决策略**：

```
检测到冲突时的处理流程：
1. 教师时间冲突（P0）→ 直接拒绝，无协商余地
2. 教室容量不足（P1）→ 自动推荐同楼栋可用教室（容量≥上课人数）
3. 教室时间冲突（P2）→ 自动推荐同时段其他可用教室
4. 班级时间冲突（P3）→ 提示冲突课程信息，建议调整到其他时段
```

**适用场景**：教务处排课时的冲突提示和自动推荐；自动排课的约束求解。

**异常处理**：

- 无可用教室时，标记该排课为"待安排教室"状态，不阻塞其他排课
- 同一教师连续排课超过4节时，系统发出"疲劳预警"（仅提示，不强制）
- 教室类型不匹配时（如实验课排到普通教室），发出类型不匹配警告

### 2.3 排课约束补充规则

**规则描述**：除冲突检测外，排课还需满足以下约束条件。

| 约束规则 | 描述 | 强制程度 |
|---------|------|---------|
| 教室容量约束 | 教室容量 ≥ 上课人数 | 强制 |
| 教室类型约束 | 实验课须排实验室，讲座须排阶梯教室 | 强制 |
| 连排约束 | 2课时以上的课程须连续排课 | 强制 |
| 教师偏好 | 教师可申报不排课时段（如周三上午不排课） | 建议（可违反） |
| 晚课限制 | 本科生课程不排第11节以后（21:00后） | 建议（可违反） |
| 午休间隔 | 上午最后一节（第4节）和下午第一节（第5节）之间不强制间隔 | 无约束 |

## 三、学籍流转规则

### 3.1 学籍状态定义

| 状态 | 英文标识 | 描述 |
|------|---------|------|
| 在读 | active | 正常在校学习 |
| 休学 | suspended | 暂停学业，保留学籍 |
| 毕业 | graduated | 完成学业，获得毕业证书 |
| 退学 | dropped | 终止学业，注销学籍 |

### 3.2 合法流转路径

```
                    ┌──────────────┐
          休学申请   │              │  复学申请
   active ────────→ suspended ────────→ active
     │                  │
     │ 退学申请         │ 退学申请
     ↓                  ↓
   dropped ←─────── dropped
     │
     │ 不可直接恢复
     ↓
  （需走重新注册流程，生成新学号）


   active ────────→ graduated
                       │
                       │ 不可逆（终态）
                       ↓
                    （终态）
```

**合法流转一览**：

| 当前状态 | 目标状态 | 流转条件 | 审批角色 |
|---------|---------|---------|---------|
| active | suspended | 学生提交休学申请 + 院系审核通过 + 教务处备案 | 院系管理员 |
| suspended | active | 学生提交复学申请 + 院系审核通过 + 缴清欠费 | 院系管理员 |
| suspended | dropped | 休学期满未复学（超过2年）或主动申请退学 | 教务处管理员 |
| active | dropped | 学生申请退学 + 院系初审 + 教务处终审 | 教务处管理员 |
| active | graduated | 满足毕业条件（见3.3）+ 院系审核 + 教务处审批 | 教务处管理员 |

**禁止流转**：

| 流转 | 原因 |
|------|------|
| graduated → 任何状态 | 毕业为终态，不可逆 |
| dropped → active | 退学不可直接恢复，需重新走入学注册流程（生成新学号） |
| dropped → suspended | 退学后学籍已注销，不存在休学状态 |

### 3.3 毕业条件

**规则描述**：学生申请毕业须同时满足以下全部条件。

| 条件 | 判定标准 |
|------|---------|
| 学分要求 | 累计获得学分 ≥ 专业培养方案规定的最低学分（通常为160~180学分） |
| 必修课要求 | 所有必修课成绩及格（无未通过的必修课） |
| 选修课学分 | 公共选修课学分 ≥ 8学分，专业选修课学分 ≥ 12学分 |
| 在读时间 | 实际在校学期数 ≥ 专业规定的最短修业年限 |
| 学籍状态 | 当前状态为 active（休学状态不可申请毕业） |

**计算公式**：

```
累计获得学分 = Σ(已通过课程的学分)
  已通过课程：grade.status = 'approved' AND total_score ≥ 60

必修课是否全部通过：
  SELECT COUNT(*) FROM grade g
  JOIN teaching_plan tp ON g.course_id = tp.course_id
  WHERE g.student_id = ? AND tp.course_nature = 'compulsory'
    AND g.status = 'approved' AND g.total_score >= 60
  结果需 = 该专业必修课总数
```

**适用场景**：毕业资格审核；学业预警（距毕业条件差距分析）。

**异常处理**：

- 存在 pending 状态成绩时，不可进行毕业审核，需先完成成绩审核
- 延长修业年限的学生（如5年制），系统配置最短修业年限参数
- 结业（未达毕业标准但修满一定学分）单独处理，颁发结业证书

### 3.4 休学/复学详细规则

**休学规则**：

| 项目 | 规则 |
|------|------|
| 申请条件 | 在读状态（active）+ 已入学满1学期 |
| 休学期限 | 最短1学期，最长2年（4个学期） |
| 审批流程 | 学生申请 → 辅导员意见 → 院系审核 → 教务处备案 |
| 生效时间 | 审核通过后，下一教学周生效 |
| 休学期间 | 保留学籍，不可选课/上课/考试；已选课程自动退选 |

**复学规则**：

| 项目 | 规则 |
|------|------|
| 申请条件 | 休学状态（suspended）+ 休学期满或提前复学 |
| 复学条件 | 缴清所有欠费 + 无未处理处分 + 原专业仍在招生 |
| 审批流程 | 学生申请 → 院系审核 → 教务处备案 |
| 年级处理 | 复学后编入原年级或下一年级（根据缺课情况） |
| 逾期处理 | 休学满2年未申请复学，自动转为 dropped（退学） |

### 3.5 退学详细规则

| 项目 | 规则 |
|------|------|
| 主动退学 | 学生本人申请 → 院系初审 → 教务处终审 |
| 劝退条件 | 累计不及格课程学分 ≥ 20学分（可配置） |
| 退学生效 | 审批通过后立即生效，学籍状态变为 dropped |
| 后续处理 | 注销校园账号（30天后）+ 通知宿舍/财务/图书馆 |
| 申诉期 | 退学通知后15个工作日内可申诉 |
